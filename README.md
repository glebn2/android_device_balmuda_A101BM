# Device tree for BALMUDA Phone (A101BM / X01A)

Unofficial LineageOS 24.0 device tree, based on LineageOS
[device/motorola/sm7250-common](https://github.com/LineageOS/android_device_motorola_sm7250-common).
One image for A101BM and X01A.

- `prebuilt/`: stock kernel, DTB and DTBO.
- `patches/`: patches to LineageOS repositories, applied by `patches/apply-patches.sh`.

Build instructions: [lineage_balmuda_phone](https://github.com/glebn2/lineage_balmuda_phone).
